# Store art: what to give Gemini, in this order

Each file is one job. Paste one, wait until Gemini writes `PROGRESS.txt`, then the next. Tell Claude "Gemini finished store <name>" and Claude processes the pictures into the shop.

1. GEMINI-STORE-BOXES-ART-FAST.md (14 pictures: the four chests closed and open, coins, ticket, jackpot, shop backgrounds) -> store-work\boxes\
2. GEMINI-STORE-PETS-ART-FAST.md (11 original baby-animal pets that replace the crewmate pets) -> store-work\pets\
3. GEMINI-STORE-ITEMS-1 ... 8-ART-FAST.md (106 shop items, cheapest first) -> store-work\items-1\ ... items-8\
4. GEMINI-STORE-VIDEOS.md (5 short Veo videos: each box opening + a shop loop) -> store-work\video\
5. GEMINI-STORE-SOUNDS.md (10 sounds, if Gemini can make audio) -> store-work\sounds\
