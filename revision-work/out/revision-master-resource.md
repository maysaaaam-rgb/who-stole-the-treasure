## G3-4. COMMON MISTAKES (Korean-L1 learners, these topics)

| Mistake | Example | One-line teacher fix |
|---|---|---|
| No article | *It is machine.* | Chant "a machine, a mirror, a plan" with a clap on **a**. |
| No 3rd-person -s | *It clean the room.* | Underline *it* and the **-s** in red. Say: "it → s". |
| No plural -s | *two eye, three horn* | Hold up fingers. Number > 1 = hiss the **s**. |
| has got / have got mix | *My monster have got…* | "I/you/they **have**, he/she/it **has**." Do a sorting game with cards. |
| Extra vowel in blends | *s-u-tar, fu-rog, peu-lan* | Clap once for *star*. Say the blend as a single sound in one breath. |
| r / l confusion | *flog* for *frog*, *pran* for *plan* | Use mirror work: tongue tip up for **l**, tongue back for **r**. |
| f / p confusion | *prog, plag* | Put top teeth on the lip for **f** and feel the air on your hand. |
| Final consonant + vowel | *nest-u, bench-i* | Tap the table on the final sound and stop. |
| Long vs short vowel | *kit* for *kite*, *tap* for *tape* | Magic-e card: slide **e** on and say "the vowel says its name". |
| sh/s before i | *sip* / *ship* mixed up | Use minimal-pair cards and finger to lips for **sh**. |
| v → b | *inbent* for *invent* | Use the bunny-teeth **v**, and show *b* and *v* on two cards. |
| Sequence word mixed | *Finally… First* order wrong | Number the steps with fingers 1-2-3-4 while saying the words. |

## G4-4. COMMON MISTAKES (Korean-L1 learners, these topics)

| Mistake | Example | One-line teacher fix |
|---|---|---|
| No past form in a story | *Alice fall down.* | Use a timeline on the board: story line = past, and add the past verb card. |
| Regular -ed on irregular verbs | *falled, runned* | Make a "Special verbs" wall: fall→fell, run→ran, see→saw. |
| Wh- question word order | *Where Alice went?* | Colour cards: Wh- + **did** + who + verb. Pupils build the question physically. |
| Long answer to yes/no question | *Yes, I like.* | Echo drill: "Do you…? Yes, I **do**." / "Can you…? Yes, I **can**." |
| bored vs boring | *Alice was boring.* | -ed = how I feel. -ing = the thing. Show a face card and a book card. |
| Extra vowel in final clusters | *nest-u, sand-u, long-u* | Whisper the last sound only and stop. Hand closes on the sound. |
| -ng as -n or -ng-g | *sin* / *sing-g* for *sing* | Hum the -ng with the mouth open; no tap at the end. |
| tr- as tu-r / ch- | *tu-ree*, *chree* | Say tr- as one quick sound. Build it as "t+r together". |
| th → s / d / tr confusion | *tree* vs *three* | Minimal-pair cards: tongue out for **th**. |
| v → b | *bisualize* for *visualize* | Use the bunny-teeth **v** and the hand-on-throat check. |
| r / l in clusters | *flee* / *free*, *brain* / *blain* | Use mirror work and slow, then fast, minimal pairs. |
| No article / plural | *Brain has many cell.* | Highlight *the* and *-s* in reading texts and read them aloud. |
